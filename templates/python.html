📚 About This Course

Python is a beginner-friendly programming language used in software development, automation, data science, artificial intelligence and machine learning.

This course is designed to help you learn Python step-by-step without depending on an internet connection.

1. Introduction to Python

Python is a high-level, interpreted programming language. It is known for its simple and readable syntax.

Example:


print("Hello, GramConnect!")
📝 Practice: Write a Python program that prints your name.

2. Variables and Data Types

A variable is used to store data in a program. Python supports data types such as integer, float, string and boolean.

Example:


name = "Gireesha"
age = 20
percentage = 92.45
is_student = True

print(name)
print(age)
print(percentage)
print(is_student)
📝 Practice: Create variables to store your name, age and college name.

3. If-Else Conditions

Conditional statements are used to execute different code depending on whether a condition is true or false.

Example:


marks = 75

if marks >= 50:
print("Pass")
else:
print("Fail")
📝 Practice: Write a program to check whether a number is positive or negative.

4. Loops

Loops are used to repeat a block of code multiple times. Python provides for loops and while loops.

Example:


for i in range(1, 6):
print(i)
📝 Practice: Write a program to print numbers from 1 to 10.

5. Functions

A function is a reusable block of code that performs a specific task.

Example:


def greet(name):
print("Hello", name)

greet("Gireesha")
📝 Practice: Create a function that takes two numbers and prints their sum.

6. Lists

A list is used to store multiple values in a single variable.

Example:


fruits = ["Apple", "Banana", "Mango"]

print(fruits)
print(fruits[0])
📝 Practice: Create a list containing five subjects you are studying.

7. Dictionaries

A dictionary stores data in key-value pairs.

Example:


student = {
"name": "Gireesha",
"course": "ECE",
"year": 3
}

print(student["name"])
📝 Practice: Create a dictionary containing your name, branch and college.

8. Mini Project

Create a simple Python calculator that performs addition, subtraction, multiplication and division.

🎯 Challenge: Build the calculator using functions and user input.
