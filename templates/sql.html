📚 About This Course

SQL stands for Structured Query Language. It is used to communicate with and manage data stored in relational databases.

This course covers SQL basics, filtering, sorting, grouping, joins and advanced queries.

1. Introduction to SQL

SQL is used to create, read, update and delete data in databases. These operations are commonly called CRUD operations.

Example:

```

SELECT * FROM employees;
```
📝 Practice: Write a query to display all records from a table named students.

2. SELECT Statement

The SELECT statement is used to retrieve data from a database table.

Example:

```

SELECT name, salary
FROM employees;
```
📝 Practice: Display the name and department of all employees.

3. WHERE Clause

The WHERE clause is used to filter records based on a condition.

Example:

```

SELECT *
FROM employees
WHERE salary > 50000;
```
📝 Practice: Find all employees whose salary is greater than 40000.

4. ORDER BY

ORDER BY is used to sort the result in ascending or descending order.

Example:

```

SELECT *
FROM employees
ORDER BY salary DESC;
```
📝 Practice: Display employees sorted by their names in ascending order.

5. GROUP BY

GROUP BY is used to group rows that have the same values. It is commonly used with aggregate functions.

Example:

```

SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```
📝 Practice: Count how many employees are present in each department.

6. SQL JOINS

Joins are used to combine data from multiple tables. Common joins include INNER JOIN, LEFT JOIN, RIGHT JOIN and FULL JOIN.

Example:

```

SELECT
e.name AS employee_name,
m.name AS manager_name
FROM employee AS e
LEFT JOIN employee AS m
ON e.manager_id = m.employee_id;
```
📝 Practice: Write a query to display employees and their managers using a self join.

7. Aggregate Functions

Aggregate functions perform calculations on multiple rows. Common functions include COUNT, SUM, AVG, MIN and MAX.

Example:

```

SELECT AVG(salary)
FROM employees;
```
📝 Practice: Find the highest salary from the employees table.

8. Subqueries

A subquery is a query written inside another SQL query.

Example:

```

SELECT name, salary
FROM employees
WHERE salary > (
SELECT AVG(salary)
FROM employees
);
```
📝 Practice: Find employees whose salary is greater than the average salary.

9. SQL Practice Challenge

Create an employee table and practice SELECT, WHERE, ORDER BY, GROUP BY and JOIN queries.

🎯 Challenge: Create two related tables and write a query using LEFT JOIN to display all records from the first table.
